# Python 3.10 ~ 3.13 only. 3.14 is NOT supported by murmurai-core (requires <3.14).
#
# torch / torchaudio are intentionally NOT listed here:
#   - Docker / cnb.cool : provided by the base image
#                         pytorch/pytorch:2.9.0-cuda12.8-cudnn9-runtime
#   - Windows / macOS   : install the CUDA build manually and BEFORE this file,
#                         otherwise pip resolves the latest (CPU-only) build first
#                         and then downgrades it, breaking torchvision/torchcodec:
#       pip install torch==2.9.0 torchaudio==2.9.0 --index-url https://download.pytorch.org/whl/cu128
#   - If pip warns "torchvision ... requires torch>=x.y": this project never imports
#     torchvision, so just run:  pip uninstall -y torchvision
#   - faster-whisper (ctranslate2) also needs CUDA 12 + cuDNN 9 DLLs on Windows:
#       pip install nvidia-cudnn-cu12==9.*   (then add site-packages\nvidia\cudnn\bin to PATH)
#
# KEEP THIS FILE ASCII-ONLY: pip <= 24.x decodes requirements files with the system
# locale (cp936 on Chinese Windows) unless the file starts with a UTF-8 BOM.
# ---------------------------------------------------------------------------
